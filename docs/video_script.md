Target length 9:30. Record against the committed demo slice: `make up`, then open
http://127.0.0.1:8501 and http://127.0.0.1:8000/docs. Every demo input below works on
`data/demo/` (prices, filings and XBRL facts up to 2026-08-31; **news only for 2026-08-10 ..
2026-08-31**), needs no API key, and makes no LLM call. Say the disclaimer once out loud and leave
it visible in the UI footer: *everything shown is a simulation, not investment advice*.

Before recording: `make down && make up`, wait for the health check, open the pages listed under
"Screen" in separate browser tabs, and open `REPORT.md`, `docs/02_architecture.md`,

## Fallbacks while recording

- If the UI shows the "Degraded mode" banner, the LLM budget variable is 0; the demo still works
  (nothing interactive needs an LLM). Say so and continue.
- If a page shows "API not reachable", run `make down && make up` and wait for the health check.
- If the first FinBERT call is slow, the model is loading (cold start about 8 s in the API eval);
  the second call is fast.
- Keep a terminal with `curl "http://127.0.0.1:8000/api/v1/signals?ticker=AAPL&as_of=2026-08-14"`
  ready as a backup for the Ticker page.
